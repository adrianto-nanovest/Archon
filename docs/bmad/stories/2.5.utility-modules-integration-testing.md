**Whitespace Normalization:**
```python
def normalize_whitespace(text: str, preserve_code: bool = False) -> str:
    """
    Normalize whitespace in text content.

    Args:
        text: Input text with potentially excessive whitespace
        preserve_code: If True, skip normalization (for code blocks)

    Returns:
        Text with normalized whitespace
    """
    if preserve_code:
        return text  # Don't modify code block whitespace

    # Collapse multiple spaces/newlines into single space
    return re.sub(r'\s+', ' ', text).strip()
```

```python
def ensure_utf8_safe(text: str) -> str:
    """Ensure text is UTF-8 safe for emoji and special characters."""
    try:
        return text.encode('utf-8', errors='replace').decode('utf-8')
    except Exception as e:
        logger.warning(f"UTF-8 encoding issue: {e}")
        return text
```

```python
def convert_embed_url(embed_url: str) -> str:
    """
    Convert iframe embed URL to original URL.

    Supports 15+ platforms: YouTube, Vimeo, Google Maps, Loom, Figma, etc.
    """
    # YouTube: youtube.com/embed/VIDEO_ID → youtube.com/watch?v=VIDEO_ID
    if 'youtube.com/embed/' in embed_url:
        video_id = embed_url.split('/embed/')[-1].split('?')[0]
        return f"https://youtube.com/watch?v={video_id}"

    # Vimeo: vimeo.com/video/VIDEO_ID → vimeo.com/VIDEO_ID
    if 'vimeo.com/video/' in embed_url:
        video_id = embed_url.split('/video/')[-1].split('?')[0]
        return f"https://vimeo.com/{video_id}"

    # Google Maps: Extract coordinates from embed URL
    if 'google.com/maps/embed' in embed_url:
        # Complex coordinate extraction logic
        return extract_google_maps_url(embed_url)

    # Generic fallback: /embed/ → /watch?v= or /
    return embed_url.replace('/embed/', '/watch?v=') if '/embed/' in embed_url else embed_url
```

#### Deduplication Utilities Pattern

**Currently in `metadata_extractor.py` (lines 30-150):**

```python
def deduplicate_by_key(items: list[dict], key_field: str) -> list[dict]:
    """
    Generic deduplication by any field.

    Args:
        items: List of dicts to deduplicate
        key_field: Field name to use as unique key

    Returns:
        Deduplicated list (first occurrence preserved)
    """
    seen: set[str] = set()
    deduplicated: list[dict] = []

    for item in items:
        key_value = item.get(key_field)
        if key_value and key_value not in seen:
            seen.add(key_value)
            deduplicated.append(item)

    return deduplicated
```

**JIRA-Specific Deduplication:**
```python
def is_jira_already_processed(issue_key: str, tracker: list[dict]) -> bool:
    """Check if JIRA issue key already exists in tracker."""
    return any(link.get("issue_key") == issue_key for link in tracker)

def is_jira_url_already_processed(url: str, tracker: list[dict]) -> bool:
    """Check if JIRA URL already exists in tracker (normalized)."""
    normalized_url = url.rstrip('/').split('?')[0]  # Remove query params
    return any(link.get("url").rstrip('/').split('?')[0] == normalized_url for link in tracker)
```

### Testing Standards

**Source:** [docs/bmad/brownfield-architecture.md - Testing Strategy](docs/bmad/brownfield-architecture.md#testing-strategy)

**Test Organization:**
- **Unit tests**: One test file per implementation file (e.g., `html_utils.py` → `test_html_utils.py`)
- **Integration tests**: Separate files for cross-handler flows (e.g., `test_full_page_integration.py`)
- **Test location**: Mirror source tree structure in `tests/` directory

**Test Framework:**
- **Pytest**: Primary test runner
- **AsyncIO support**: Use `@pytest.mark.asyncio` for async tests
- **Mocking**: Use `unittest.mock.AsyncMock` and `MagicMock` for dependencies
- **Fixtures**: Use pytest fixtures for shared test data

**Coverage Requirements:**
- **Per-handler**: 90%+ coverage (statement coverage)
- **Integration**: 95%+ coverage (branch coverage)
- **Critical paths**: 100% coverage (error handling, deduplication, metadata extraction)

**Test Execution:**
```bash
# Run all confluence tests
uv run pytest python/tests/server/services/confluence/ -v

# Run with coverage report
uv run pytest python/tests/server/services/confluence/ --cov=src.server.services.confluence --cov-report=term-missing

# Run specific test file
uv run pytest python/tests/server/services/confluence/test_full_page_integration.py -v

# Run specific test
```

**Test Naming Conventions:**
- Unit tests: `test_{function_name}_{scenario}()`
- Integration tests: `test_{feature}_{integration_point}()`
- IV tests: `test_iv{number}_{requirement_description}()`
