#### Form Validation Requirements

**Confluence URL:**
- Must be valid URL format
- Must start with `https://`
- Should end with `.atlassian.net/wiki` (warning if not)

**Email:**
- Standard email format validation
- Required field

**API Token:**
- Non-empty string
- Minimum length: 10 characters (Atlassian tokens are longer)
- Password input type (hidden)

**Space Key:**
- Uppercase letters and numbers only: `/^[A-Z0-9]+$/`
- Common space keys: DEVDOCS, ENGINEERING, WIKI

**Deletion Strategy:**
- Default: `"weekly_reconciliation"`
- Options array:
```typescript
const deletionStrategies = [
  { value: "weekly_reconciliation", label: "Weekly Reconciliation", description: "Check for deleted pages once per week" },
  { value: "every_sync", label: "Every Sync", description: "Check every sync (slower but more accurate)" },
  { value: "on_demand", label: "On Demand", description: "Only check when manually triggered" },
];
```
