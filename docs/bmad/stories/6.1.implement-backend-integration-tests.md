### Database Schema Reference

**Source:** [docs/bmad/brownfield-architecture/data-models-and-apis.md](../../brownfield-architecture/data-models-and-apis.md#confluence-tables-to-create-in-migration-010)

**`confluence_pages` table:**
```sql
CREATE TABLE confluence_pages (
  page_id TEXT PRIMARY KEY,
  source_id TEXT NOT NULL REFERENCES archon_sources(source_id) ON DELETE CASCADE,
  space_key TEXT NOT NULL,
  title TEXT NOT NULL,
  version INTEGER NOT NULL,
  last_modified TIMESTAMPTZ NOT NULL,
  is_deleted BOOLEAN DEFAULT FALSE,
  path TEXT,  -- Materialized hierarchy path
  metadata JSONB NOT NULL,  -- Rich metadata (JIRA links, mentions, etc.)
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

**`archon_crawled_pages` (unified chunks):**
```sql
-- Confluence chunks link via metadata
SELECT * FROM archon_crawled_pages
WHERE metadata->>'page_id' = '12345';

-- CASCADE DELETE ensures cleanup when source deleted
-- via: source_id REFERENCES archon_sources(source_id) ON DELETE CASCADE
```

### Integration Test Approach

**Key Difference from Unit Tests:**
- Unit tests mock all dependencies (Supabase, Confluence API)
- Integration tests use a **real test database** (Docker PostgreSQL) with mocked Confluence API only
- Integration tests verify actual database state changes
